Два Blender
одновременно.
Без терминала.

macOS не открывает второй экземпляр Blender — клик по иконке просто возвращает к уже запущенному окну. Этот лаунчер снимает ограничение и заодно показывает проекты и автосейвы до запуска.

Зачем это нужно

Один Blender на весь Mac — это ограничение системы, а не программы

Blender прекрасно работает в нескольких копиях: у каждой свои сцена, память и рендер. Мешает только то, как macOS запускает приложения.

Как обычно

Клик по иконке

macOS видит, что процесс уже запущен, и просто переключает на его окно. Второй сцены не будет.

Обходной путь

Команда в терминале

Работает, но каждый раз нужно помнить open -n или полный путь внутрь бандла.

С лаунчером

Кнопка «Новое окно»

Запускает отдельный процесс напрямую из бандла. Столько копий, сколько нужно — ⌘N для следующей.

Возможности

Всё, что нужно решить до запуска Blender

Несколько окон

Отдельный процесс на каждое окно: своя сцена, свой рендер, свой краш. ⌘N — следующее.

Находит проекты сам

Ищет файлы .blend по домашней папке через Spotlight — за доли секунды, включая те, что Blender уже забыл.

Спасает после краша

Показывает автосейвы из обоих мест, где их прячет Blender, отсортированные по свежести.

Любая версия Blender

Находит все установки и показывает номера версий. Старый проект открывается той версией, в которой он сделан.

Список под рукой

Недавние и найденные проекты в одном списке с фильтром по имени. Выбрал — нажал Return.

Светлая и тёмная

Переключение в один клик прямо в панели инструментов. Можно оставить на усмотрение системы.

Восстановление после краша

Blender прячет автосейвы в двух разных местах

Часть попадает во временную папку системы, часть — в скрытую папку .autosave рядом с самим проектом. Второе место легко не найти: Spotlight скрытые папки не индексирует. Лаунчер собирает оба источника в один список.

Оформление

Тема переключается одной кнопкой

Светлая, тёмная или как в системе — выбор запоминается между запусками.

Установка

Три шага, минута времени

Скачать архив

Возьмите Blender-Launcher-macOS-arm64.zip со страницы релизов и распакуйте.

Перенести в Программы

Перетащите Blender Launcher.app в папку «Программы».

Открыть первый раз

Правый клик по приложению → «Открыть». Дальше запускается как обычно.

xattr -cr "Blender Launcher.app"
Почему macOS ругается при первом запуске. Приложение подписано локально и не проходило нотаризацию Apple — для этого нужен платный аккаунт разработчика. Открытие через правый клик снимает вопрос один раз, либо выполните команду выше. При первом поиске проектов система также спросит доступ к папкам — без него список найденных файлов останется пустым.
